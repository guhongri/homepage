# Robotics and Material Design Lab at HKUST

Static multi-page website for the Robotics and Material Design Lab, led by Prof. Hongri (Richard) Gu. The repository is published through GitHub Pages at [guhongri.com](https://guhongri.com).

The site includes the lab's research philosophy, three research genres, eight illustrated research stories, people, linked publications, recruitment guidance, teaching, and contact information.

## Structure

- `index.html` — homepage
- `research.html` — Understand / Create / Solve research framework
- `how-we-work.html` — research process and group principles
- `stories.html` and `story-*.html` — illustrated research narratives
- `people.html` — PI and group directory
- `publications.html` — DOI-linked publication list
- `teaching.html` and `course-*.html` — teaching overview and course details
- `assets/` — official HKUST identity asset, profile photo, course photograph, and cropped paper figures
- `CNAME` — custom domain used by GitHub Pages

The source generator and image preparation workspace are maintained separately from this deployment repository.
